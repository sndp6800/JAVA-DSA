# Java & Data Structures

A practice repository for Java problem solving, data structures and algorithms. Solutions are organized by problem so the implementation and approach can be reviewed together.

## How to use this repository

Browse a problem directory and inspect its solution. Some submissions use platform-provided entry points rather than a standalone `main` method; run those in the corresponding problem environment or add a local harness.

For future solutions, include the approach, time/space complexity and important edge cases. This is a learning collection, not a production library or a claim of exhaustive test coverage.
